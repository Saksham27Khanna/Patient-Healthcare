# Healthcare Management Web App

## 📌 Project Overview
This is a frontend-based Healthcare Management Web Application built using React.  
The app helps users manage their medical activities like appointments, medications, and personal dashboard tracking in a simple and responsive UI.

It includes authentication flow (login/signup), protected routes, and multiple feature pages such as Dashboard, Appointments, Medications, and Profile. The application is designed with a focus on usability, clean UI, and state management using React hooks and localStorage.

---

## 🛠 Tech Stack

### Frontend
- React.js
- React Router DOM
- Tailwind CSS (or CSS if used)
- JavaScript (ES6+)

### State Management
- React Hooks (useState, useEffect)
- LocalStorage (for persistence)

### Deployment
- Vercel

### Known Limitations
This project is currently frontend-only and does not include any backend integration.
All data is managed using React state and localStorage, so it is not persistent on a server.
No real authentication system is implemented (login is simulated).
Data may reset on browser refresh in some cases due to localStorage handling.
Backend features like database storage and API integration are not yet added.
